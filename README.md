# Sales ETL Pipeline

Python ETL project using API data, CSV processing, SQL loading, and analytics.

## Stack
- Python
- SQL
- Pandas
- PostgreSQL
- SQLAlchemy

## Architecture
API → Python (ETL) → PostgreSQL → SQL Analytics

## Steps
1. Extract data from REST API
2. Clean and transform using Python (pandas)
3. Load structured data into PostgreSQL
4. Perform analytical queries using SQL

## Key Features
- Flattened nested JSON data
- Data cleaning and validation
- Schema design and database loading
- SQL-based Analytics Queries

## How to Run
1. Install dependencies
2. Run main.py script
3. Execute SQL queries
